# Eligibility Check

A one-page tool for clinical partners to check, at intake, whether a patient's home address is in a Florida Rural Health Transformation Program (RHTP) rural area. It shows a green **Eligible** or red **Not Eligible** result with the qualifying pathway, and a line to copy into the chart.

## How it decides
1. **ZIP code first.** 235 ZIP codes are eligible in full and 696 are not; those answer instantly with no lookup.
2. **Address next.** For ZIP codes that are only partly rural, PO Box ZIP codes, or when no ZIP code is given, the street address is sent to the U.S. Census Bureau's public geocoder. That returns the address's 2020 census block, county and tract, which are checked against:
   - REDI rural counties (Pathways 2 and 3)
   - REDI communities and Rural Areas of Opportunity (Pathway 3)
   - HRSA rural census tracts (Pathway 4)
   - eligible ZIP codes (Pathway 4 and the ≥50% rule)
3. A PO Box or an address the geocoder can't match gets a yellow "check the address" message, never a guess.

Rules follow AHCA's RHTP *Definition of Rural* (March 2026) as applied by CommHIT, with AHCA's decisions of November 7, 2026: Century and Dundee treated as expired, and Flagler County not eligible. Sources: FloridaCommerce REDI list (effective March 5, 2026), HRSA FORHP rural data (September 2025), USDA 2020 RUCA codes, 2020 Census. This is not an official AHCA determination.

## Privacy
Everything runs in the user's browser. The page stores nothing and sends nothing to CommHIT. The only outside request is the street address sent to the Census geocoder, and only when the ZIP code can't decide. Staff should never enter a name or date of birth.

## Files
- `index.html`: the page (no build step; Google Fonts is the only other request)
- `eligibility-data.json`: lookup data (REDI counties, HRSA tracts, REDI/RAO census blocks, ZIP statuses). Regenerated by CommHIT's pipeline (`10_checker_data.py`) when the rules or source data change.
